# ⚫ 온라인 오목 ⚪

친구에게 링크 하나만 보내면 바로 두는 온라인 오목이에요. 설치나 가입이 필요 없어요.

**▶ 플레이: https://rewq4434.github.io/-/**

## 친구와 두는 방법
1. 위 주소를 열고 **「친구와 하기 (방 만들기)」**를 눌러요.
2. **「초대하기」** → 카카오톡으로 링크를 보내요.
3. 친구가 링크를 열고 **「바로 입장하기」**를 누르면 대국이 시작돼요.

> 방을 만든 사람(방장)의 화면이 서버 역할을 해요. 대국 중에는 방장이 창을 닫지 않게 해 주세요.
> 초대 링크를 보내느라 잠깐 카톡으로 넘어갔다 오는 건 괜찮아요.

## 휴대폰 앱으로 쓰기
- **아이폰:** 사파리로 주소를 열고 → 공유 버튼 → **홈 화면에 추가**
- **안드로이드:** 크롬으로 주소를 열고 → **「📲 홈 화면에 앱으로 설치」**를 누르거나, 화면의 **「안드로이드 앱(APK) 받기」**를 눌러요.

## 규칙과 기능
- 15×15 판에서 흑이 먼저 둬요. 같은 색 돌을 5개 이상 이으면 이겨요(자유룰).
- 무르기(상대 동의 필요), 기권, 다시 하기(흑백 교체), 채팅, 관전(세 번째 사람부터)을 할 수 있어요.
- 휴대폰에서는 한 번 탭하면 미리보기가 뜨고, 같은 자리를 한 번 더 탭해야 둬요(오터치 방지).

## 개발자용

| 파일 | 역할 |
|---|---|
| `public/core.js` | 방/게임 규칙 (서버와 브라우저가 같이 씀) |
| `public/app.js` | 화면, 그리기, 연결 (P2P / 서버) |
| `public/config.js` | 연결 방식 설정 |
| `server.js` | (선택) Node WebSocket 서버 |
| `android/` | Capacitor 안드로이드 프로젝트 |

### 연결 방식 두 가지
- **P2P (기본):** GitHub Pages처럼 서버가 없는 곳에서 써요. 방장의 기기가 게임을 진행(`core.js`)하고, 메시지는 무료 공개 MQTT 중계 서버(EMQX, HiveMQ, Mosquitto)로 주고받아요.
  - WebRTC 직접 연결을 쓰지 않아서 LTE/5G나 회사 와이파이에서도 연결돼요.
  - 중계 서버 하나가 죽으면 자동으로 다음 서버로 넘어가요. 목록은 `config.js`의 `OMOK_BROKERS`로 바꿀 수 있어요.
- **서버 모드:** `npm install && npm start`로 Node 서버를 띄워 접속하면 자동으로 이 방식이 돼요. 방장이 나가도 방이 유지되고, 「아무나와 빠른 대전」도 쓸 수 있어요. Render 같은 Node 호스팅에 올리면 돼요(`render.yaml` 포함).

### GitHub Pages 배포
`gh-pages` 브랜치에 `public/` 폴더의 내용과 `omok.apk`가 올라가 있어요.

### APK 빌드
```
npx cap sync android
cd android && ./gradlew assembleDebug
```
